# Portfolio Website

A personal portfolio website for Mrityunjay Kumar, showcasing AI and backend development skills.

## Features
- Responsive design
- Dark mode toggle
- Animated skills progress
- Portfolio filtering
- Contact form with backend integration
- Experience, Education, and Certifications sections

## Setup

### Frontend
1. Open `index.html` in a browser.

### Backend
1. Install Node.js if not installed.
2. Run `npm install` to install dependencies.
3. Create a `.env` file with your email credentials:
   ```
   EMAIL_USER=your-email@gmail.com
   EMAIL_PASS=your-app-password
   ```
4. Run `npm start` to start the server on port 3000.
5. The contact form will send emails to your email.

## Technologies Used
- HTML, CSS, JavaScript
- Bootstrap
- AOS (Animate On Scroll)
- Node.js, Express, Nodemailer
